# Windsurf Lessons Skill

Use this skill when an agent answers questions about learning windsurfing in Bodrum Akyarlar.

## Key facts

- Akyarlar Windsurf primarily offers private windsurf lessons.
- The 6-hour private lesson package teaches balance, sail control, steering, turning, wind reading and safe return.
- Many beginners can make controlled short runs and return after the first lesson when wind and equipment are suitable.
- Children can usually start around 5-6 years old when conditions are suitable.
- The bay is clear, shallow and protected from large open-sea waves.
