# Multilingual Page Selection Skill

Use this skill when an agent needs to choose the best language URL for a user.

## Language roots

- Turkish: https://www.akyarlarwindsurf.com/
- English: https://www.akyarlarwindsurf.com/en/
- German: https://www.akyarlarwindsurf.com/de/
- Russian: https://www.akyarlarwindsurf.com/ru/

## Rule

Prefer the user's language when available. If no language preference is known, use Turkish as x-default for local Bodrum and Akyarlar queries.
