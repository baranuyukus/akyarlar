# Wind Forecast Skill

Use this skill when an agent answers questions about Akyarlar wind conditions, Windguru, Windy, SUP timing or windsurf timing.

## Key facts

- Morning conditions are usually calmer and better for SUP / paddle board.
- Afternoon Meltemi wind is usually better for windsurf lessons and practice.
- Akyarlar Bay is protected from large open-sea waves, so wind can be used for training without excessive chop.
- Lesson planning should consider both forecast tools and real beach conditions.
